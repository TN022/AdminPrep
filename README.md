# AdminPrep — GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `adminprep`.
2. Extraia o ZIP e envie todos os arquivos para a raiz do repositório (Add file > Upload files).
3. Em Settings > Pages, escolha Deploy from a branch, main, /(root), Save.
4. Aguarde a publicação e abra https://SEU-USUARIO.github.io/adminprep/ no Safari.
5. Compartilhar > Adicionar à Tela de Início > Adicionar. Abra o app instalado com internet uma vez e aguarde o carregamento. Depois teste em modo avião.

Videoaulas e provas externas exigem internet. O progresso é local ao navegador/app e não sincroniza entre aparelhos. Para atualizar o cache após mudanças, altere a versão em sw.js. GitHub Pages é público; não envie dados pessoais.
